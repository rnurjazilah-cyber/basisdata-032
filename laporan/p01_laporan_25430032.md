4. JAWABAN TITIK ANALISIS

Titik Analisis 1
XAMPP menampilkan nama MySQL, tetapi server pada komputer saya adalah MariaDB versi 10.4.32. Versi server diperiksa agar lingkungan yang digunakan diketahui.

Titik Analisis 2
ERROR 1045 berarti proses login atau autentikasi gagal. Hal ini dapat terjadi karena password atau pasangan akun dan host tidak sesuai.

Titik Analisis 3
ERROR 1044 berarti akun tidak memiliki izin membuka basis data yang diminta. ERROR 1142 berarti akun tidak memiliki izin menjalankan perintah tertentu, seperti membuat tabel.

Titik Analisis 4
Pada autentikasi cookie, pengguna memasukkan akun dan password saat membuka phpMyAdmin. Password tidak sebaiknya ditulis langsung dalam berkas konfigurasi yang dapat dibaca orang lain.

5. HASIL LATIHAN DAN MODIFIKASI

Akun tamu\_032 diberi hak SELECT pada kopma\_032. Setelah memilih basis data, saya mencoba membuat tabel. MariaDB menolak perintah tersebut dengan ERROR 1142 karena akun tamu tidak memiliki hak untuk membuat tabel.

Skrip lingkungan menggunakan CREATE DATABASE IF NOT EXISTS dan CREATE USER IF NOT EXISTS agar perintah pembuatan dapat dijalankan kembali dengan lebih aman.
